# Mavericks Inventory Management Application

1. Project Overview
Project Name
Mavericks Inventory Management Application
Project Type
Internal, Generic Inventory Management BAU Application
Nature of Project
This is a Business As Usual (BAU) system designed to be used daily across the organization for inventory tracking and control.

2. Purpose of the Project
The purpose of this application is to provide a centralized, approval‑driven, and auditable system to manage inventory for multiple item types using Excel uploads and system workflows.
The system is not limited to one product. It can manage inventory for various items such as:

T‑Shirts
Headsets
Mouse
Coffee Mugs
Any other physical inventory items
